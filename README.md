\# Discord Chess



DiscordとWeb UIを連携したチェス対局システムです。



\## 概要



このプロジェクトでは、\*\*Webをチェス対局の本体\*\*として使用し、Discordは\*\*対局の監視・観戦用\*\*として利用します。



対局者はWeb UIから駒を操作し、ゲーム状態はサーバー側で管理されます。



Discordには現在の盤面、手番、チェック状態、勝敗、観戦URLなどが表示されます。



\## 主な機能



\- Webブラウザでのチェス対局

\- 白・黒のターン制

\- 合法手判定

\- 王手判定

\- チェックメイト判定

\- ステイルメイト判定

\- キャスリング

\- アンパッサン

\- ポーンの昇格

\- 投了

\- 複数対局の同時進行

\- 対局ごとのゲームID

\- 対局状態の保存

\- Discordでの対局監視

\- Discordからの観戦URL表示
